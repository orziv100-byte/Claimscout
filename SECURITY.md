# Responsible security reporting

Poolindex Closed Beta is not a bug-bounty program. There is no promise of payment for reports.

## Contact

Send reports to: security@POOLINDEX_DOMAIN (configuration required before launch: set `POOLINDEX_CONTACT_SECURITY`).

## What to include

- A short description of the issue
- Steps to reproduce on a system you are authorized to test
- Impact (what an attacker could do)
- Poolindex version if known

Do **not** include real tester passwords, seed phrases, private keys, or other people's personal data in the report.

## Testing rules

You are not authorized to:

- Run destructive tests, DDoS, or resource-exhaustion against the live Beta
- Access accounts or wallets that are not yours
- Exfiltrate `var/beta/` user data

## Response

The operator will try to acknowledge reports sent to the configured security contact. This file is not a legal SLA.
